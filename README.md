# Code Tamagotchi

Питомец-тамагочи в боковой панели VS Code: получает опыт от написания кода и активности в Git (коммиты, пуши), растёт по уровням и разблокирует аксессуары.

## Возможности

- Иконка **Тамагочи** на панели активности → представление «Питомец» со статистикой и настроением.
- Кормление, игра и другие действия через палитру команд (**Code Tamagotchi**).
- Смена скина питомца.
- Интеграция с расширением **Git**: опыт за коммиты и пуши.

## Настройки

- `code-tamagotchi.idleTimeoutMinutes` — через сколько минут без действий питомец скучает (по умолчанию значение задаётся в `package.json`).

## Локальная установка `.vsix`

```text
code --install-extension code-tamagotchi-<version>.vsix
```

Или через **Extensions** → меню ⋮ → **Install from VSIX…**.

## Требования

- Установлено расширение **Git** (зависимость VS Code для награды за коммиты/пуши).
